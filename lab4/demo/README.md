# Демонстрація

## Обов'язково для здачі

Записати відео запуску застосунку та зберегти тут як `demo.mp4` або `demo.mov`.

На відео варто показати:
1. `ollama list` — завантажені моделі.
2. `python3 app/main.py` та сторінку http://127.0.0.1:8765.
3. Відмову від посилки без пошкодження.
4. Відмову **з пошкодженням** і зміну процедури.
5. Принаймні один запит до локальної LLM (прапорець пояснення).
6. `python3 app/checks.py` з результатом маршрутизації та `bench_results.csv` після реальних вимірювань.

`routing_results.json` — справжні результати функціональних тестів. Це не результати оцінювання LLM. Відео й результати моделей створюються після запуску на комп'ютері студента.
