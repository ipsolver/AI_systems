# Лабораторна робота №4. Локальний запуск і оптимізація мовних моделей

**Тема практичної частини:** ситуаційний навігатор для працівника поштового відділення.

Цей проєкт демонструє локальну мовну модель через Ollama та застосунок, який показує навчальні покрокові сценарії: відмова, пошкодження, нестача вкладення, повернення, помилка в даних одержувача, затримка доставки та інші ситуації.

## Структура

- `local_models_demo.ipynb` — оригінальні демо-клітинки лекції 5 та окрема частина з теоретичними поясненнями, експериментальним кодом і шаблоном звіту 1.8.
- `app/` — повний код вебзастосунку, навчальна база процедур, тести та скрипти оцінювання.
- `bench_results.csv` — місце для реальних вимірювань `before` та `after`; до першого запуску є тільки заголовок.
- `demo/` — автоматичні результати функціональних тестів, майбутні відео та оцінювання LLM.

## Порядок виконання

1. Виконати клітинки `local_models_demo.ipynb` у Colab із доступним GPU (для секції 2 потрібен CUDA), заповнити `VOTES` у розділі 2.5.
2. У розділі теоретичних питань звірити пояснення із власними фактичними результатами, особливо питання 4, 5, 8, 9, 13, 15, 17.
3. Дізнатися характеристики **свого** комп'ютера і визначити придатну модель/квантизацію.
4. Установити Ollama, завантажити моделі, запустити `bench.py` з `--label before` та `--label after` (інструкція в `app/README.md`).
5. Протестувати 10 сценаріїв маршрутизації та окремо зберегти/оцінити 10 пояснень кожної локальної моделі.
6. Дописати звіт 1.8 лише фактичними даними, записати демонстрацію у `demo/`.
